# Deck Research Brief

Use this skill for researcher-style work before slide HTML is created.

## Read First

1. `lecture-deck/source.md`
2. `lecture-deck/slide-spec.json` if it exists
3. User-provided references

## Workflow

1. Confirm the topic, audience, duration, goal, and constraints.
2. Separate facts into:
   - slide-visible claims
   - speaker-note-only context
   - weak or missing evidence
3. Prefer official or primary sources for date, law, institution, and ceremony claims.
4. Add concrete evidence pointers: URL, file path, title, and publication/update date when available.
5. Do not invent slide structure unless assigned. If asked for slide spec input, provide concise claim/evidence candidates.

## Output

Use Korean with exactly these sections:

```text
발견:
수행:
판단:
미해결:
```

Keep it under 500 words unless asked for a full source brief.
